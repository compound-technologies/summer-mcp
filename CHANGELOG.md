# Changelog

## 0.2.0

- Publish Summer's existing MCP transport and operation contract as a standalone source package.
- Supply authentication, rate limits and execution through an explicit host backend.
- Preserve official SDK support for modern discovery and supported 2025 clients.
- Include independent protocol and authorization-boundary tests and a synthetic loopback demo.

This version identifies the source package. Hosted deployment and Registry metadata releases are tracked separately; source publication does not enable a feature for a company.
